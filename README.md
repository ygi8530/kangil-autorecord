# Quick Rec (kangil-autorecord)

Galaxy Watch에서 **홈 키 두 번 = 녹음 시작, 다시 두 번 = 저장**. 저장된 녹음은 **폰으로 자동 전송**됩니다.
워치와 폰이 끊겨 있을 때 녹음한 것은 워치에 보관했다가 **다시 연결되는 즉시** 넘어갑니다.

| 구성 | 위치 | 역할 |
|---|---|---|
| 워치 앱 | `wear/` | 홈 키 더블 프레스로 녹음 토글, 폰 전송 대기열 |
| 폰 앱 | `mobile/` | 녹음 수신·보관함(재생·즐겨찾기·메모·공유·삭제), 설정 |

검증 기기: Galaxy Watch6 40mm (SM-R930, Wear OS / Android 16), Galaxy S25 Edge (SM-S937N, Android 16)

---

## 1. 설치

### 1-1. 미리 빌드된 APK로 설치 (가장 쉬움)
`dist/` 폴더의 두 APK를 **함께** 설치합니다.

| 파일 | 설치 대상 |
|---|---|
| `dist/quickrec-watch.apk` | 워치 (0.3.1) |
| `dist/quickrec-phone.apk` | 폰 (0.4.1) |

> ⚠️ **워치 앱과 폰 앱은 반드시 같은 빌드(같은 서명)여야 서로 통신합니다.** 한쪽만 직접 빌드해서 설치하면 전송이 안 됩니다.
> 직접 빌드할 때는 두 앱을 같은 PC에서 함께 빌드해 함께 설치하세요.

### 1-2. PC 준비 (Windows 기준)
1. JDK 17, Android SDK, adb 설치 — Android Studio를 설치하면 한 번에 됩니다.
   (winget: `EclipseAdoptium.Temurin.17.JDK`, `Google.AndroidStudio`, `Google.PlatformTools`)
2. 소스로 빌드하는 경우 저장소 루트에 `local.properties` 생성:
   ```
   sdk.dir=C\:\\Users\\<사용자>\\AppData\\Local\\Android\\Sdk
   ```
3. 빌드:
   ```
   gradlew.bat :wear:assembleDebug :mobile:assembleDebug
   ```
   결과물: `wear/build/outputs/apk/debug/wear-debug.apk`, `mobile/build/outputs/apk/debug/mobile-debug.apk`

### 1-3. 워치에 설치 (Galaxy Watch는 USB 데이터 단자가 없어 Wi-Fi ADB만 가능)
1. 워치: **설정 → 워치 정보 → 소프트웨어 정보 → 소프트웨어 버전 7번 탭** → 개발자 모드
2. 워치: **설정 → 개발자 옵션 → ADB 디버깅 ON, Wi-Fi를 통한 디버깅 ON**
3. 워치를 PC가 접근할 수 있는 Wi-Fi에 연결
   - 워치는 폰과 블루투스로 연결돼 있으면 Wi-Fi를 자동으로 끊습니다. **설치하는 동안만 폰 블루투스를 끄세요.**
4. 워치: **Wi-Fi를 통한 디버깅 → 새 기기 페어링** → 화면의 코드·IP:포트로
   ```
   adb pair <워치IP>:<페어링포트> <6자리코드>
   adb connect <워치IP>:<연결포트>        # "Wi-Fi를 통한 디버깅" 첫 화면의 포트 (페어링 포트와 다름)
   adb -s <워치IP>:<연결포트> install -r dist/quickrec-watch.apk
   ```
   PC와 워치가 다른 공유기(서브넷)에 있으면 자동 검색은 안 되지만 IP·포트를 직접 넣으면 됩니다.

### 1-4. 폰에 설치
- **방법 A (adb):** 폰 **설정 → 개발자 옵션 → 무선 디버깅** → 페어링 코드로 기기 페어링 → 워치와 같은 방식으로 `adb pair` / `adb connect` / `adb install -r dist/quickrec-phone.apk`
- **방법 B:** APK 파일을 폰으로 옮겨 직접 열어 설치 ("출처를 알 수 없는 앱" 허용 필요)

### 1-5. 처음 설정
1. 워치 앱 목록에서 **Quick Rec** 실행 → **마이크 허용, 알림 허용** (허용 후 화면이 바로 닫히는 건 정상)
2. 워치: **설정 → 유용한 기능 → 키 사용자 설정 → 두 번 누르기 → Quick Rec**
3. 폰에서 **Quick Rec** 실행 → "음악 및 오디오 접근" 허용 (이전 설치에서 받은 녹음까지 목록에 표시하는 용도)
4. 폰 블루투스를 켜서 워치와 연결

## 2. 사용법

### 워치
| 동작 | 결과 |
|---|---|
| 홈 키 두 번 | 녹음 시작 — 진동 1번, 화면 위 마이크 표시(초록 점), 워치페이스로 바로 복귀 |
| 녹음 중 홈 키 두 번 | 저장 — 진동 2번, 폰으로 전송 대기열에 들어감 |
| 녹음 중 알림 → "정지" | 저장 (홈 키 두 번과 같음) |

- 화면이 꺼져 있어도, 다른 앱을 보고 있어도 동작합니다.
- **시작 후 진동을 느낀 다음** 두 번 누르세요. 너무 빠르게 연타하면 워치가 "4번 누르기"로 판정해 반응하지 않습니다.
- 홈 키 **5번**은 SOS(긴급 전송)입니다. 연타에 주의하세요.
- 녹음 중 앱이 강제 종료돼도 녹음은 남아 있다가, 다음 녹음을 시작할 때 자동 저장·전송됩니다.

### 폰 (보관함)
- **목록:** 날짜별 / 월별 / 즐겨찾기 전환, 검색(이름·메모). **오늘 녹음은 파란 점과 배경으로 강조**
- **새로고침:** 아래로 당기기 또는 상단 ↻ 버튼 (새 녹음이 들어오면 자동으로도 갱신)
- **녹음을 탭하면 그 자리에서 재생:** 재생/일시정지, 위치 이동, 10초 앞뒤, 속도 1x / 1.5x / 2x
- **녹음별 메뉴:** ★ 즐겨찾기, 이름 바꾸기, 메모, 공유, 다른 앱으로 열기, 삭제 (왼쪽으로 밀어도 삭제)
- **여러 개 한 번에:** 녹음을 길게 누르거나 상단 **선택** → 체크 → 하단에서 즐겨찾기 / 공유 / 삭제. **전체 선택** 지원. 이 앱이 저장하지 않은 파일이 섞여 있으면 Android 확인 창이 한 번 뜹니다
- **설정(⚙):** 워치 연결 상태, **"폰에 저장되면 워치에서 삭제"** 토글, 보관함 통계, 저장 위치
- 폰 저장 위치: `내장 저장공간/Recordings/WatchRecorder/` (파일 앱·다른 플레이어에서도 보임)

### 전송 동작
- 워치가 녹음을 저장 → 폰이 연결돼 있으면 **수 초 안에** 전송
- 끊겨 있으면 워치 대기열에 보관 → **폰이 다시 연결되는 즉시** 자동 전송 (보조로 15분마다 재시도, 워치 재부팅 후에도 유지)
- 폰이 파일을 받아 **크기까지 확인하고 저장한 뒤에만** 워치 대기열에서 빠집니다. 중간에 끊기면 다시 보내고, 폰은 같은 파일을 중복 저장하지 않습니다.
- "워치에서 삭제"가 켜져 있으면 폰 저장이 확인된 파일만 워치에서 지웁니다.

## 3. 제한 사항 (실기기 검증 결과, 상세: `docs/verification.md`)
- **삼성 기본 음성녹음 앱과는 연동되지 않습니다.** 삼성 앱은 외부 앱이 녹음을 시키거나 파일을 넘길 공개 방법이 없고, 같은 폴더에 넣어도 인식·동기화하지 않습니다. 그래서 자체 폰 앱으로 전송합니다.
- 더블 프레스 시 투명 화면이 아주 잠깐(수십 ms) 떴다 닫힙니다. Android 정책상 마이크 녹음은 앱이 화면에 있는 순간에만 시작할 수 있어서 생략할 수 없습니다.
- 시스템 마이크 표시(초록 점)와 "녹음 중" 알림은 정책상 항상 표시됩니다.
